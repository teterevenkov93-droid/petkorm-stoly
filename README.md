# Столы производственные для петкорма

Нержавеющая сталь AISI 304. Две позиции: рабочий стол 2000×650 и стол 800×640 со свесом.

- **[Смотреть модели и чертежи](https://teterevenkov93-droid.github.io/petkorm-stoly/)** — 3D-модель с вращением, регулировка высоты 1100…1200, спецификация, чертёж в трёх проекциях.
- `стол_2000x650x1100.stl`, `стол_800x640x1100.stl` — геометрия для просмотра и раскроя.

Модели предварительные, до согласования размеров узлов.
